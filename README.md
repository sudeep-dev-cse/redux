# Redux Counter App

A simple Counter Application built using React and Redux Toolkit.

## Features

- Increment Counter
- Decrement Counter
- Increase Counter By Custom Amount
- Redux Toolkit State Management
- Responsive UI

## Tech Stack

- React
- Redux Toolkit
- JavaScript
- CSS
- Vite

## Project Structure

src/
├── features/
│ └── CounterSlice.js
├── App.jsx
├── main.jsx

## Installation

1. Clone the repository

git clone <repository-url>

2. Install dependencies

npm install

3. Run project

npm run dev
